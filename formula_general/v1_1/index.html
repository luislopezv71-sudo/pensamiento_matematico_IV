Etapa 1. Definición y teoría

Una ecuación cuadrática tiene la forma general:

ax² + bx + c = 0, con a ≠ 0

Sus soluciones se calculan con la fórmula general:

−b ± √b² − 4ac2a

El discriminante es Δ = b² − 4ac. Si Δ > 0 hay dos raíces reales distintas; si Δ = 0 hay una raíz real doble; si Δ < 0 no hay raíces reales.

Para la función y = ax² + bx + c, el vértice se obtiene con xv = −b2a y yv = f(xv).

Ejemplo: x² − 4x + 3 = 0. a=1, b=−4, c=3; Δ=16−12=4; x=(4±2)/2, por lo tanto x=1 y x=3. Su vértice es V(2,−1).

¿Para qué sirven las ecuaciones cuadráticas?

Antecedente histórico y aplicaciones

Desde la Antigüedad se resolvían problemas de áreas y longitudes que hoy expresamos mediante ecuaciones cuadráticas. Matemáticos de Babilonia estudiaron procedimientos equivalentes a completar el cuadrado; siglos después, al-Juarismi sistematizó métodos algebraicos.

Actualmente estas ecuaciones ayudan a estudiar trayectorias de objetos, diseñar arcos y estructuras, calcular dimensiones de terrenos y analizar modelos de costos, ingresos o ganancias.

Pregunta: ¿cuándo toca el suelo una pelota lanzada? Para responder, buscamos cuándo su altura es cero: las raíces de la ecuación.

El discriminante: ¿cuántas soluciones reales existen?

Antes de resolver una ecuación cuadrática, calculamos un número llamado discriminante. Su signo permite anticipar cuántas veces la gráfica cruza o toca el eje horizontal (eje X).

Δ = b² − 4ac

Se lee: «delta es igual a be al cuadrado menos cuatro por a por c». El símbolo Δ (delta) representa el discriminante.

Δ > 0 · Dos raíces reales

La parábola corta dos veces el eje X.

Ejemplo: x² − 4 = 0
Δ = 16; x = −2 y 2.

Δ = 0 · Una raíz real doble

La parábola toca una vez el eje X, en su vértice.

Ejemplo: x² = 0
Δ = 0; x = 0 (doble).

Δ < 0 · Sin raíces reales

La parábola no toca el eje X.

Ejemplo: x² + 1 = 0
Δ = −4; no hay raíces reales.

Explora los tres casos: presiona un botón y observa cómo cambian los coeficientes y la gráfica del simulador.
Recuerda: «sin raíces reales» no significa «sin solución en absoluto»: existen soluciones complejas, que se estudian en cursos posteriores.
