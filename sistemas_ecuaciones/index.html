Ruta de aprendizaje

Comprender → visualizar → practicar → demostrar → evaluar. Tiempo sugerido: cuatro sesiones de 50 minutos. Registra todos los procedimientos en el cuaderno.

Al terminar identificarás incógnitas, resolverás sistemas 2×2, graficarás rectas, comprobarás resultados y distinguirás sistemas con una, ninguna o infinitas soluciones.

1. ¿Qué es un sistema de ecuaciones?

Dos ecuaciones lineales con las mismas incógnitas forman un sistema. Resolverlo consiste en encontrar los valores de x e y que cumplen ambas ecuaciones al mismo tiempo.

a₁x + b₁y = c₁
a₂x + b₂y = c₂

Ejemplo: 2x + y = 8 y x − y = 1. La solución es x=3, y=2, porque 2(3)+2=8 y 3−2=1.

Interpretación gráfica

Una solución: rectas secantes. Ninguna: rectas paralelas diferentes. Infinitas: la misma recta.

Aplicación moderna

Dos planes de datos móviles: uno cobra cuota fija y otro una tarifa por GB. Su punto de intersección identifica un consumo con el mismo costo.

Procedimiento por eliminación

¿Qué significa el determinante?

D = a₁b₂ − a₂b₁. Si D ≠ 0 hay una solución única. Si D = 0, se comparan las ecuaciones para identificar si son compatibles con infinitas soluciones o incompatibles.

3. Métodos algebraicos

Sustitución

  1. Despeja una incógnita en una ecuación.
  2. Sustituye en la segunda.
  3. Resuelve la ecuación resultante.
  4. Regresa y calcula la otra incógnita.

Igualación

  1. Despeja la misma incógnita en ambas ecuaciones.
  2. Iguala las dos expresiones.
  3. Resuelve la incógnita restante.
  4. Sustituye y comprueba.

Eliminación o reducción

  1. Multiplica ecuaciones si es necesario.
  2. Suma o resta para eliminar una incógnita.
  3. Calcula la incógnita restante.
  4. Sustituye y verifica.

Método gráfico

  1. Representa las dos ecuaciones.
  2. Identifica su intersección.
  3. Lee las coordenadas (x, y).
  4. Comprueba en las ecuaciones.
